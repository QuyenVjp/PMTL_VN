# DX_ONBOARDING — 5-Phút Developer Experience

Mục tiêu: Developer mới chạy được dev environment trong 5 phút.

> **Related**: `TEAM_GUIDE.md`, `Justfile`

---

## 1. Quick Start (5 phút)

```bash
# 1. Clone repo
git clone https://github.com/pmtl-vn/pmtl.git
cd pmtl

# 2. Prerequisites check
just doctor

# 3. Bootstrap everything
just bootstrap

# 4. Start dev stack
just dev-core

# 5. Open browser
# Web:   http://localhost:3000
# API:   http://localhost:3001/api
# Admin: http://localhost:3002
```

---

## 2. Prerequisites

| Tool | Version | Check | Install |
|------|---------|-------|---------|
| Node.js | 20.18.0+ | `node -v` | [nvm](https://nvm.sh) |
| pnpm | 10.30+ | `pnpm -v` | `corepack enable && corepack prepare pnpm@latest --activate` |
| Docker | 27+ | `docker -v` | [Docker Desktop](https://docker.com) |
| Just | 1.0+ | `just --version` | `cargo install just` or `brew install just` |

Windows đặc biệt:
- Dùng PowerShell hoặc Git Bash
- WSL2 tùy chọn (recommended cho Docker performance)
- Clone ở ngoài OneDrive folder

## 3. Just Recipes (Cheat Sheet)

```bash
# Setup
just bootstrap       # Full setup: deps + Docker + migrate
just doctor          # Check prerequisites

# Development
just dev-core        # Start core stack (web + api + db)
just dev-full        # Start full stack (+ search + cache)
just dev-stop        # Stop all containers
just dev-rebuild     # Rebuild containers
just dev-logs        # Tail all logs

# Verification
just verify-web      # Lint + typecheck + test web
just verify-api      # Lint + typecheck + test api
just verify-all      # All checks

# Database
just db-migrate      # Run pending migrations
just db-reset        # Reset + seed (destructive!)
just db-studio       # Open Prisma Studio

# Utilities
just smoke           # Quick health check
just clean           # Remove node_modules + .next
```

## 4. Environment Setup

### 4.1 Copy env files

```bash
# Root env (monorepo)
cp .env.example .env

# App-specific
cp apps/web/.env.example apps/web/.env.local
cp apps/api/.env.example apps/api/.env
cp apps/admin/.env.example apps/admin/.env.local
```

### 4.2 Essential env vars

```bash
# .env (root)
DATABASE_URL="postgresql://pmtl:pmtl@localhost:5432/pmtl_dev"
DIRECT_URL="postgresql://pmtl:pmtl@localhost:5432/pmtl_dev"

# apps/api/.env
JWT_SECRET="dev-secret-change-in-production"
```

### 4.3 Docker dev secrets

```bash
# infra/docker/.env (auto-generated by bootstrap)
POSTGRES_PASSWORD=pmtl
REDIS_PASSWORD=pmtl
```

## 7. Troubleshooting

### Port already in use

```bash
# Find process
lsof -i :3000
# Or on Windows
netstat -ano | findstr :3000

# Kill it
just dev-stop
# Or manually
docker compose down
```

### Docker not starting

```bash
# Check Docker daemon
docker info

# Restart Docker Desktop
# Or on Linux: sudo systemctl restart docker
```

### Database connection refused

```bash
# Check container running
docker ps | grep postgres

# Restart if needed
just dev-rebuild

# Check connection
just db-studio
```

### pnpm install fails

```bash
# Clear cache
pnpm store prune

# Remove lockfile and retry
rm pnpm-lock.yaml
pnpm install
```

### TypeScript errors after git pull

```bash
# Regenerate Prisma client
pnpm -F @pmtl/api db:generate

# Full clean rebuild
just clean
just bootstrap
```

## 9. Local-Prod Parity

Dev environment mirrors production:
- Same Node version (20.18.0)
- Same database (Postgres 17)
- Same cache (Valkey 8 when enabled)
- Same search (Meilisearch 1.12)

Differences (dev-only):
- Hot reload enabled
- Debug logging verbose
- HTTPS disabled (use `just dev-ssl` for SSL testing)
- No CDN/Cloudflare
