# Phóng Sinh — Thủ Tục, Thời Gian, Công Đức — Life Liberation: Procedures, Timing, Merit Benefits

> **Nguồn:** Khai thị chính thức Pháp Môn Tâm Linh
> **Trạng thái:** Verified source
> **Cập nhật:** 2026-04-05

## Purpose

Guide practitioners through the complete life liberation (phóng sinh) ceremony, from understanding merit benefits, selecting auspicious timing, choosing appropriate species and locations, to performing releases individually or in groups. Phóng sinh combines three types of giving (charity) and cultivates compassion while healing karmic debt.

## Owner Module

`altar-management` — LifeLiberationService / MeritCalculationEngine

## Actors

- **Practitioner**: Initiates phóng sinh, selects species/location/timing
- **Proxy (optional)**: Releases on behalf of others
- **Group Coordinator**: Manages collective ceremonies
- **Wisdom Archive**: Records phóng sinh acts and merit attribution
- **Auspicious Calendar Service**: Validates timing (lunar calendar, Bodhisattva feast days)

## Trigger

1. User initiates phóng sinh session
2. User seeks health recovery, karmic remedy, or vow repentance
3. System recommends phóng sinh as part of repentance plan
4. User prepares for auspicious calendar date

### Part D: Species Selection & Quantity

| Species | Water Type | Min Size | Typical Quantity | Notes |
|---------|-----------|----------|------------------|-------|
| **Carp** (cá chép) | Freshwater | Hand-sized+ | 100–1000 | Most common; hardy survival |
| **Silver fish** (cá bạc) | Freshwater | Hand-sized+ | 100–1000 | Good survival rate |
| **Grass carp** (cá cỏ) | Freshwater | Hand-sized+ | 50–500 | Larger species |
| **Turtle** (qua / rùa) | Freshwater/marine | 2–3 cm+ | 5–50 | Symbolic longevity; smaller quantity |
| **Shrimp/Crab** (tôm/cua) | Saltwater | Small | 100–500 | Abundant; easier to release |
| **Freshwater eel** (lươn) | Freshwater | Medium+ | 20–100 | Good survival |
| **Bird** (chim) | Aerial | Various | 1–20 | Rare but high merit; complex logistics |

**Guidelines:**
- **Never select fish too small** — seller may have raised them specially for phóng sinh (you create excess karma)
- **Order only 0.5–1 day before release** — prevents prolonged captivity
- **Larger creatures = higher merit** — one turtle release = merit of 100 fish (symbolic)

### Part E: Release Locations

| Location Type | Requirements | Feasibility | Notes |
|---------------|--------------|-------------|-------|
| **Public rivers/lakes** | Non-polluted, not commercial fishing | High | Verify no chemical pollution, no nets/traps |
| **Temple ponds** | Maintained, safe habitat | High | Many temples facilitate phóng sinh |
| **Natural springs** | Pristine, flowing water | Medium | Best ecosystem but less accessible |
| **Designated eco-zones** | Green/protected area status | Medium | Check local environmental registry |
| **Ocean** (saltwater species only) | Deep water, away from nets | Low | Requires boat access; rare |

**Location validation (mandatory):**
- ✅ Check water source (freshwater vs. saltwater match)
- ✅ Verify no commercial fishing activity
- ✅ Confirm no chemical/industrial pollution
- ✅ Ensure released creatures will survive
- ❌ **NEVER release in:**
  - Heavily trafficked urban waterways
  - Actively fished commercial zones (creatures re-caught = wasted merit)
  - Polluted rivers/lakes (creatures die from toxins = karmic harm reversal)

### Part F: Proxy Release (Thay Người Phóng Sinh)

| Scenario | Method | Merit Attribution | Notes |
|----------|--------|------------------|-------|
| Release on behalf of ill relative | Proxy pays, system records | 80% to ill relative, 20% to proxy | Relative's awareness = higher merit |
| Release without recipient knowing | Proxy pays with intention | 70% to recipient (diminished) | Lack of awareness reduces effect |
| Relative provides funds | Proxy releases with relative's money | 90% to relative, 10% to proxy | Relative's financial sacrifice = stronger karma shift |
| Parent/elder's repentance | Child pays + releases | 95% to parent, 5% to child (as filial act) | Honoring parents = highest merit |

**Proxy Guidelines:**
- Declare proxy relationship clearly at release: "I am releasing on behalf of [Name]"
- Recite: "[Name] provided the funds; [Name] receives the merit"
- **Critical**: Do NOT repeatedly mention your own name during ceremony (diminishes attribution)
- Proxy release still counts as "compassion cultivation" for proxy (20% benefit retained)

**Post-ceremony:**
- Group shares merit together (collective energy amplification)
- Can offer Buddha meal or shared meal afterward (optional)
- Group can document ceremony with photo (audit trail)

## Write Path (Pseudocode API)

### 1. Validate Timing (Calendar Engine)

```
POST /api/altar-management/phong-sinh/validate-timing

1. Extract selectedDate from DTO
2. Convert to lunar calendar date
3. Check against auspicious calendar:
   - IF Bodhisattva feast day → multiplier = 2.0x
   - ELSE IF full/new moon → multiplier = 1.5x–2.0x
   - ELSE IF user birthday → multiplier = 2.5x
   - ELSE IF New Year period → multiplier = 3.0x
   - ELSE → multiplier = 1.0x

4. Check time of day:
   - IF evening (after sunset) → warning: merit reduced
   - IF night → warning: merit reduced to 0.3x
   - IF daytime → normal

5. RETURN { isAuspiciousDate: boolean, meritMultiplier: number }
```

### 2. Validate Location Eco-Compatibility

```
POST /api/altar-management/phong-sinh/validate-location
(See life-liberation-eco-compatibility-check.md for full flow)

1. Extract waterType, releaseLocation from DTO
2. Geocode location → fetch pollution/fishing data
3. Match speciesType to waterType
4. Block if incompatible; warn if pollution/fishing active
5. RETURN { isValid: boolean, blocks: [], warnings: [] }
```

### 3. Calculate Merit

```
POST /api/altar-management/phong-sinh/calculate-merit

1. Base merit = 1.0 (all phóng sinh starts at 1.0)
2. Apply multiplier from timing validation
3. Add creature value bonus:
   - Fish = 1.0 per creature
   - Turtle = 100.0 (symbolic longevity)
   - Bird = 150.0 (rarest; highest merit)
4. IF proxy mode with "full awareness" → 90% to target
5. IF group mode with 4+ people → 1.3x collective multiplier
6. Total merit = base × timeMultiplier × creatureValue × awareness × groupBonus

Example: 100 carp on Lunar New Year with Bodhisattva feast day = 100 × 3.0 × 1.0 = 300 merit units

7. RETURN meritResult with attribution breakdown
```

### 4. Record Session + Audit

```
POST /api/altar-management/phong-sinh/complete-session

1. Extract all DTO fields
2. Validate location (eco check)
3. Calculate merit (step 3 above)
4. Create LifeLiberationSession record:
   - sessionId, date, time, species, quantity, location, participants
   - meritEarned, meritMultiplier, attribution
   - auditTrail with timestamp, witness count

5. Update practitioner profile:
   - Add merit to their account
   - Update lifespan recovery (if targeting health)
   - Log "phong_sinh_completed" audit event

6. IF proxy mode:
   - Route 80–95% merit to target practitioner
   - Update target's lifespan/health score

7. RETURN LifeLiberationMeritResult with summary message
```

### 5. Display Merit Summary + Health Impact Projection

```
GET /api/altar-management/phong-sinh/{sessionId}/summary

1. Calculate projected health/lifespan impact:
   - IF targeting vow repentance → show lifespan recovery days
   - IF targeting illness → show recovery probability (+5–15% per 100 fish)
   - IF routine merit → show accumulated spiritual energy

2. RETURN human-readable summary:
   "You released 100 carp on Lunar New Year (3x merit multiplier).
    Total merit: 300 units → +1.5 years to your lifespan projection.
    Combined with Lễ Phật Đại Sám Hối, you will recover from your vow breach."
```

## Notes for AI/Codegen

1. **Auspicious Calendar Integration**: Maintain database of lunar calendar dates + Bodhisattva feast days. Integrate with external lunar calendar API (or hardcode annual data).

2. **Merit Calculation Engine**:
   - Base merit = creature count × creature value (1.0 per fish, 100 per turtle, 150 per bird)
   - Multiplier = time-based × awareness × group bonus
   - Attribution = split merit across primary/secondary beneficiaries based on relationship

3. **Proxy Blessing Logic**:
   - If target awareness = 'full' → 90% merit to target
   - If target awareness = 'partial' → 80% merit to target
   - If target awareness = 'none' → 70% merit to target
   - Always retain 10%+ for proxy (compassion cultivation)

4. **Group Dynamics**:
   - 4–5 people = 1.3x multiplier
   - 6–10 people = 1.2x (harder to coordinate)
   - 10+ people = recommend professional coordinator

5. **Health Impact Projection** (if targeting illness/vow repentance):
   - Per 100 fish = +1 year to lifespan projection
   - Per turtle = +5 years (symbolic longevity)
   - Display as "estimated lifespan recovery" (not guaranteed)

6. **Pre-release Validation**: Always run eco-check (pollution, water type, fishing zones) before allowing session completion.
