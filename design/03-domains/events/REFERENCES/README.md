# References for Events

Tài liệu tham khảo, nguồn chính thống, và ví dụ minh hoạ cho domain events.

## Nội dung thuộc thư mục này

- Tài liệu giáo lý / kinh điển liên quan đến sự kiện Phật giáo
- Quy tắc nghiệp vụ gốc (canonical rules) được trích dẫn trong USE_CASES
- Ví dụ dữ liệu mẫu hoặc lịch sự kiện tham khảo
- Ghi chú nghiên cứu từ nguồn bên ngoài
