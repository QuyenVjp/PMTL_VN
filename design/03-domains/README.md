# Domain Packs

Thư mục này dành cho logic lõi dự án theo domain business.

Mỗi domain nên hướng tới:

```text
<domain>/
  DECISIONS.md
  MODULE_MAP.md
  CONTRACTS.md
  SCHEMA_PLAN.md
  STATES/
  USE_CASES/
  REFERENCES/
```

## Rule

Đây là nơi trả lời:

- domain này sở hữu gì
- boundary với domain khác ra sao
- write-path nào tồn tại
- contract nào phải giữ
