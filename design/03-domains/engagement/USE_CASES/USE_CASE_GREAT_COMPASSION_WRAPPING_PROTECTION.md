**Module:** `engagement`, `little-house`

**Source:** Dharma Door Core Texts, Mantra Polarity Rules

## 📋 Tóm Tắt Nghiệp VỤ

**Để NNN có năng lượng mạnh nhất, phải dùng Chú Đại Bi "bao bọc" các kinh văn khác.**

### 📿 THUẬT TOÁN "BỌC BỒNG":
- **Mở:** 9 biến Chú Đại Bi
- **Cơm tâm:** Xen kẽ Chú Đại Bi giữa các kinh
  - 9 biến + Kinh 1 + 3 biến
  - + Kinh 2 + 3 biến
  - + Kinh 3 + 3 biến
  - + Kinh 4 + 3 biến
- **Đóng:** 9 biến Chú Đại Bi

## 🎯 Acceptance Criteria

### AC1: Algorithm Initialization
**GIVEN** start NNN recitation  
**WHEN** select wrapping mode  
**THEN** 
- Show algorithm choice:
  ```
  🧠 CÀI ĐẶT: THUẬT TOÁN "BỌC BỒNG"
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Để tối ưu hóa năng lượng NNN:
  
  ○ Chế độ 1: Niệm thường (không bọc)
     - Niệm kinh bình thường
  
  ● Chế độ 2: Thuật Toán "Bao Bồng" ⭐
     (KHUYÊN DÙNG)
     - Dùng Chú Đại Bi bao bọc
     - Năng lượng mạnh gấp 10x
     - Vong linh không dám cướp
  
  ○ Chế độ 3: Chỉ Chú Đại Bi
     - Niệm riêng Chú Đại Bi
     - Công đức vẫn khá
  
  [Chọn Chế Độ 2 - Bao Bồng]
  ```

### AC3: Kinh 1 + 3 Chú Đại Bi Wrapping
**GIVEN** opening complete  
**WHEN** start sutras  
**THEN** 
- Guide alternation:
  ```
  📖 BƯỚC 2: KINH 1 + CHÚ ĐẠI BI
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Tiếp theo:
  
  🟢 NIỆM KINH 1: [Tâm Kinh]
  
  "Quán Tự Tại Bồ Tát, hành thâm 
  Bát Nhã Ba La Mật Đa..."
  (Niệm đến hết)
  
  🔴 NGAY SAU ĐÓ: 3 BIẾN CHÚ ĐẠI BI
  
  "Lăm Vân Ất Tế Bà" (x3)
  
  💡 Lý do xen kẽ:
  - Chú Đại Bi tạo "lớp bảo vệ" 
    giữa các kinh
  - Vong linh không thể can thiệp
  - Năng lượng tập trung vào người 
    cần kinh
  
  [Hoàn Tất Kinh 1 + 3 Biến]
  ```

### AC4: Kinh 2 + 3 Chú Đại Bi

  "Lăm Vân Ất Tế Bà" (x3)

  🔴 + 3 BIẾN CHÚ ĐẠI BI

**GIVEN** all sutras complete  
**WHEN** finalize  
**THEN**

  "Lăm Vân Ất Tế Bà" (x9)
