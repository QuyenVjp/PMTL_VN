# USE CASE: Virtual Image Protection Guard
**Module:** `content`, `wisdom-qa`  
**Phase:** 39 - Chi Tiết Quy Tắc Thắp Hương & Nghi Thức Thực Hương  
**Source:** Buddhism in Plain Terms, Virtual Space Protection

---

## 📋 Tóm Tắt Nghiệp VỤ

**Tuyệt đối cấm bái lạy vào hình ảnh Bồ Tát trên màn hình hoặc châm nhang vật lý vào ảnh ảo.**

### 🚫 TUYỆTÙ ĐỐI CẤM:
1. **Lạy vào màn hình điện thoại/máy tính**
2. **Thắp nhang thật vào ảnh Bồ Tát trên kinh sách chưa khai quang**
3. **Làm động tác vật lý ngoài trời trước hình ảnh ảo**

### ⚠️ LÝ DO NGUY HIỂM:
- Năng lượng bị các vong linh khác chiếm đoạt
- Rắc rối, xui xẻo, thậm chí nguy hiểm cho bản thân

---

## 🎯 Acceptance Criteria

### AC1: Screen Bowing Prevention
**GIVEN** user try to perform physical bowing to device  
**WHEN** detect orientation + proximity  
**THEN** 
- Block with urgent warning:
  ```
  🚨 NGAY LẬP TỨC: TUYỆTÙ ĐỐI CẤMÙ!
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  ❌ TUYỆTÙ ĐỐI KHÔNG ĐƯỢC:
  
  Bái lạy vào điện thoại / máy tính!
  
  Hệ thống phát hiện:
  ⚠️  Bạn đang cử động cúi đầu 
      gần màn hình
  ⚠️  Màn hình có hình Bồ Tát
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  💀 NGUY HIỂM:
  
  Khi bạn bái lạy vào hình ảo trên 
  màn hình (chưa khai quang), các 
  thế lực linh giới khác (vong linh, 
  quỷ quái, linh thú) sẽ:
  
  1. Chiếm mất năng lượng công đức
  2. Bám vào bạn
  3. Gây rắc rối, xui xẻo, nguy hiểm
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  ✅ CÁCH ĐÚNG:
  
  Dùng TÂMÙ HƯƠNG (niệm tâm):
  - Quán tưởng trong đầu
  - Không làm động tác vật lý
  - Niệm Kinh + Mantra
  - Khấn nguyện bằng lời/tâm
  
  [Tìm Hiểu Tâm Hương]
  ```

### AC2: Physical Incense to Screen Prevention
**GIVEN** user try to light physical incense to device  
**WHEN** detect flame + screen proximity  
**THEN** 
- Emergency block:
  ```
  🚨 NGUY HIỂM: NGÀY LẬP TỨC DỪNG LẠI!
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  ⚠️  TUYỆTÙ ĐỐI CẤM:
  Thắp nhang thật vào ảnh Bồ Tát 
  trên màn hình!
  
  NGUY HIỂM:
  ✗ Hình ảnh chưa khai quang
  ✗ Lửa gần điện tử → cháy
  ✗ Các linh thể khác sẽ chiếm mất 
    công đức
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Hãy:
  1. Dùng TÂMÙ HƯƠNG thay vào
  2. Không cần lửa hay khoi
  3. Chỉ cần tâm niệm mạnh mẽ
  
  [Hướng Dẫn Tâm Hương]
  ```

### AC3: Image Purity Check
**GIVEN** user show image of Buddha/Bodhisattva  
**WHEN** verify authenticity  
**THEN** 
- Warn if unpurified:
  ```
  ⚠️  KIỂM TRA: ẢNH HÀY ĐÃ KHAI QUANG?
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Ảnh Bồ Tát của bạn:
  - Có phải từ chùa chiếu?
  - Hay từ mạng internet?
  - Hay từ sách Kinh khai quang?
  
  Nếu ảnh:
  ❌ Từ internet / máy tính tự in
  ❌ Chưa được Thầy/Sư Cô khai quang
  ❌ Không rõ nguồn gốc
  
  → TUYỆTÙ ĐỐI KHÔNG được:
  ✗ Làm lễ trước ảnh đó
  ✗ Thắp nhang thật
  ✗ Lạy vái
  
  ✅ CHỈ dùng TÂMÙ HƯƠNG (niệm tâm)
  
  [Tôi Hiểu - Dùng Tâm Hương]
  ```

### AC4: Smartphone Orientation Lock
**GIVEN** app with Buddha image  
**WHEN** detect screen facing down during recitation  
**THEN** 
- Show caution:
  ```
  ⚠️  LỮU Ý: CÁCH CẦM ĐIỆN THOẠI
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Không được:
  ✗ Để điện thoại nằm xuống (mặt 
    Bồ Tát hướng mặt đất)
  ✗ Để điện thoại vào túi xỉu
  ✗ Để dưới gối / gầm ghế
  
  ✅ CẤY:
  ✓ Cầm bình thường
  ✓ Nhìn vào hình ảnh
  ✓ Niệm tâm (không bái lạy vật lý)
  ✓ Nếu cần bái lạy → rút bộ pin, 
    để điện thoại ở vị trí tôn trọng
  ```

### AC5: Outdoor Bowing Guard
**GIVEN** user try outdoor bowing to device image  
**WHEN** geolocation + body orientation detected  
**THEN** 
- Show warning:
  ```
  ⚠️  NGUYEANU: BÁI LẠY NGOÀI TRỜI
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Hệ thống phát hiện:
  📍 Vị trí: NGOÀI TRỜI / Công cộng
  
  ⚠️  Cảnh báo:
  - Bái lạy vào màn hình ngoài trời 
    là rất nguy hiểm
  - Năng lượng sẽ bị "phân tán"
  - Các linh thể hoang dã có thể 
    bám vào bạn
  
  ✅ PHẢI LÀM:
  - Vào nhà yên tĩnh
  - Dùng TÂMÙ HƯƠNG (niệm tâm)
  - Không cần bái lạy vật lý
  
  [Hiểu Rồi]
  ```

### AC6: Offline Purity Reminder
**GIVEN** app offline mode with downloaded images  
**WHEN** user about to interact  
**THEN** 
- Remind purity rules:
  ```
  ✅ NHẮCÙ NHỚ: PURITY (Thanh Tịnh)
  
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  Ảnh Bồ Tát trong App:
  
  ✓ Đã được khai quang
  ✓ Được bảo vệ bởi hệ thống
  ✓ An toàn để quán tưởng
  
  ✅ CÓ THỂ:
  - Niệm Kinh nhìn vào ảnh
  - Dùng TÂMÙ HƯƠNG
  - Quán tưởng hình ảnh
  
  ❌ KHÔNG:
  ✗ Làm động tác vật lý lạy
  ✗ Để điện thoại úp xuống
  ✗ Để ngoài trời
  
  [Xác Nhận]
  ```

### AC7: Audit Virtual Interaction
**GIVEN** user recite/meditate  
**WHEN** log session  
**THEN** 
- Track safety compliance:
  ```typescript
  {
    sessionId: <uuid>,
    userId: <uuid>,
    type: 'HEART_INCENSE_SESSION',
    deviceUsed: 'SMARTPHONE' | 'WEB',
    imageVerified: true,
    purified: true,
    physicalBowingAttempted: false,
    physicalIncenseAttempted: false,
    safetyCompliance: true,
    timestamp: now()
  }
  ```
