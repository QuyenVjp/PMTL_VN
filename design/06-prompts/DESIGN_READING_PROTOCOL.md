# DESIGN_READING_PROTOCOL

Prompt skeleton để AI đọc `design/` đúng thứ tự:

1. đọc `design/README.md`
2. đọc `design/01-repo-constitution/DECISIONS.md`
3. đọc `design/01-repo-constitution/ROOT_DOC_OWNERSHIP.md`
4. đọc owner docs đúng lane đang sửa
5. không lấy overview doc làm authority nếu owner doc đã có
6. nếu docs conflict, sửa owner doc trước rồi mới scaffold/code
