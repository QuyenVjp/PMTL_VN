HIGH-IMPACT CONSTRAINTS (Implementation Must Follow)
===================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ C1. QUERY KEY FACTORY PATTERN                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ Rule:     All query keys → factory functions in apps/admin/src/features/   │
│           {feature}/query-keys.ts                                           │
│ Why:      TanStack Query v5 best practice; prevents string key drift       │
│ Violates: Hardcoded keys in components → maintenance burden                 │
│ Example:  ✓ {feature}Keys.list(filters)                                    │
│           ✗ ['admin-posts', 'list']                                        │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ C2. INVALIDATION SPECIFICITY                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ Rule:     Invalidate only affected keys, never broad queryClient invalidate │
│ Why:      Stale cache; performance degradation on partial updates          │
│ Pattern:  invalidateQueries({ queryKey: {feature}Keys.lists() })          │
│           + {feature}Keys.detail(id)                                        │
│           + dashboard cascade if applicable                                 │
│ Violates: queryClient.invalidateQueries() (no params)                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ C3. PUBLISH → PUBLIC CACHE TRIGGER                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ Rule:     All content publish mutations must call platform/cache webhook    │
│ When:     After onSuccess (list + detail cache invalidated client-side)    │
│ Route:    POST /internal/revalidate                                        │
│ Body:     { source: 'post-publish' | 'guide-publish' | ... , id }         │
│ Violates: Skipping webhook → public pages serve cached old content         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
